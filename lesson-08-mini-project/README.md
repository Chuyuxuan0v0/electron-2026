# 第 8 课：实战小项目与面试可讲 Demo

## 学习目标

- 综合运用前 7 课知识，完成一个**可演示、可写进简历**的 Electron 小项目
- 项目需包含：窗口与生命周期、IPC、菜单/托盘（可选）、打包（可选）、Vue3 + Pinia、安全实践
- 能清晰向面试官介绍：项目功能、技术选型、你负责的部分、遇到的难点与解决方式

## 学习内容大纲

1. **项目选题建议**
   - 本地小工具：如剪贴板历史、本地 Markdown 预览器、简易文件管理器、系统信息查看器
   - 或与你现在业务相关的小工具：如配置生成器、日志查看器（只读本地文件）
   - 不要求大而全，要求**完整闭环**：打开应用 → 使用核心功能 → 可打包/可演示

2. **技术整合检查清单**
   - 主进程：窗口、菜单、托盘、IPC、生命周期
   - 渲染进程：Vue3 + Pinia，至少一个 store、若干组件
   - 通信：preload + contextBridge，至少 2～3 个业务 API（如读文件、写配置、弹窗）
   - 安全：contextIsolation、无 nodeIntegration、CSP（可选）
   - 打包：能打出当前系统安装包（可选但建议做）

3. **面试可讲要点**
   - 项目背景与目标用户
   - 架构：主进程/渲染进程分工、为什么用 preload、状态如何持久化
   - 难点：例如多窗口通信、打包体积优化、某次安全加固
   - 若时间紧：至少把 1～7 课的小 Demo 串成一个「学习型项目」并能讲清楚每课对应哪块

## 成果量化

| 成果项 | 验收标准 |
|--------|----------|
| 可运行项目 | 有一个完整 Electron 应用，包含上述至少 4 项技术点（如窗口+IPC+Vue3+Pinia） |
| 可演示 | 能在 3～5 分钟内演示核心功能（打开应用、完成 1～2 个主流程） |
| 可讲述 | 能口头或笔记写出：项目介绍、技术栈、你的实现思路、1～2 个难点与解决方式（便于面试时表达） |
